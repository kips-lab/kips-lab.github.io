# kips-lab.github.io

The KIPS group website, published at https://kips-lab.github.io/.

## Editing

This is a dependency-free static website. Edit `index.html` for people, research, alumni, visitors and workshop links. Edit `assets/style.css` for presentation. No JavaScript or build step is required. Keep the `.nojekyll` file so GitHub Pages serves the site directly.

For a local preview, run `python -m http.server 8000` in the repository and open http://localhost:8000/.

## Publication

GitHub Pages should publish `main` from the repository root (`/`). Pushes to `main` update the public site.
